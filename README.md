# Nour EL Din — Portfolio

## التشغيل
فك ضغط الملف بالكامل، ثم افتح `index.html`. احتفظ بمجلد `assets` بجوار ملفات HTML وCSS وJS. لا توجد خطوة build ولا حاجة إلى npm.

## دليل التعديل
- **الألوان والخطوط:** في بداية `style.css` تحت `VARIABLES CSS`.
- **تصميم كل سكشن:** له عنوان مستقل في CSS مثل `HOME SECTION` و`SERVICES SECTION`.
- **الموبايل والتابلت:** تحت `BREAKPOINTS / RESPONSIVE` في نهاية CSS.
- **البريد:** `CONTACT_EMAIL` في بداية `main.js`.
- **نصوص الكتابة المتحركة:** قائمة `words` تحت `HOME TYPED TEXT`.
- **تفاصيل المشاريع:** قائمة `projects` تحت `PROJECT DATA` في JS.
- **كروت المشاريع:** سكشن `work` في `index.html`. عند إضافة مشروع، طابق رقم `data-project` مع ترتيبه في قائمة JS، والتي تبدأ من صفر.
- **صور المشاريع:** داخل `assets/img`. الصور الخمس المرفقة مدمجة بالفعل، وتظهر كاملة دون قص. تظهر نسخة أكبر عند فتح تفاصيل المشروع.
- **باقي المحتوى:** عدّل النصوص داخل `index.html`.

CSS وJS منسّقان بأربع مسافات، مع سطر لكل خاصية وعناوين وفواصل بين الأجزاء. لا توجد ملفات مضغوطة أو minified.
